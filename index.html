作業の保存（詳細）

編集内容のブラウザへの書き込みは「今すぐ保存」のときのみです（自動保存はしません）。別PCでは共有されません。

ブロックを追加

コンテナ選択中にブロックを追加すると、その内側に配置されます。

レイヤー

使用方法説明

リスト上＝奥 ／ 下＝手前（新規ブロックは下に追加。↓↑で変更）

コンテナは ▶ で内側のレイヤーを開きます。表示の ON/OFF は名前の左のチェックです。

左端の ⠿ をドラッグすると、別の親（キャンバス／コンテナの内側）へ移動できます。コンテナの行へドロップで内側へ入ります。Shift を押しながらコンテナ行へドロップすると、そのコンテナの「前」に兄弟として置きます。

選択中のブロック: Ctrl+C / Ctrl+V（Mac は ⌘）でコピー・ペースト。テキスト入力中はショートカット無効です。

Ctrl / ⌘ を押しながらブロックやレイヤーをクリックで複数選択。ドラッグでまとめて移動。他ブロックと左・中央・右（横）や上・中央・下（縦）がそろうとハイライト色の補助線が出ます。

ブロックがありません。

    テンプレート

    あらかじめ定義した LP 構成をキャンバスに一括で読み込みます（既存のブロックは消えます）。

    テンプレート JSON を更新したのに古い画面のままのときは、このブラウザに保存した LP（自動保存）が優先されています。「その他の保存・読込」からブラウザの保存を削除するか、新規作成してからテンプレートを選び直してください。

    選択中のテンプレートに対し、PC ビューを *.desktop.json、スマホ編集ビューを *.mobile.json に保存します。パスワードはサーバーで検証されます（npm start で起動したとき）。

    指示・長さ・トーンをまとめて送信します（合計500文字まで）。生成結果は反映先に従ってキャンバスへ入ります。

    編集ビュー

    PC とスマホは別々に保存されます。スマホでは横幅を狭くして配置を調整してください。

    キャンバス

    編集エリアの論理幅です。スマホ用レイアウトは上部の「スマホ」ビューで編集します。

    ワークエリアの高さの目安です。ブロックが下にはみ出すときは、その分だけ自動で伸びます。
